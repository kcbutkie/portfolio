Project 4 - Interactive Altair Charts

Overview

We've used Altair in class before, and we've done a little bit with interactivity (tooltips and an interactive window) but there's a lot more that can be done to make visuals interactive. This tutorial will go through some of the methods that can be done to make interactive visuals.

These tutorials are based off of the example visuals found on Vega-Altair's example gallery. However, the tutorial below goes further in-depth about what to change in the code and some ways to customize the interactive features.

For these graphs, I used the data that I had pulled from the Google Trends time series activity (activity 7), so feel free to load in your data (or you can download the dataset I used for the examples HERE) in order to follow along.

Initial Chart

Before adding in some interactivity, let's first create a simple scatterplot to show us what we're working with. The code below is copy/pasted from a Google Colab notebook that can be found at the bottom of this page if you'd like to see how the blocks were structured and their corresponding outputs.

Code: 


	import altair as alt, pandas as pd
	from google.colab import files
	uploaded = files.upload()

After running this code, you can upload your data file into the Google Colab notebook. 


	dataset = pd.read_csv("/content/time_series.csv")

Replace the path within the quotation marks with the path to your uploaded dataset. 


chart1 = alt.Chart(dataset).mark_circle(color="purple").encode(
    x = alt.X("Blue:Q").title("Popularity of Searches for Blue"),
    y = alt.Y("Red:Q").title("Popularity of Searches for Red"),
    tooltip = ["Blue", "Red"]
)
chart1

This creates our scatterplot. Swap out everything that says Blue with whatever search term you'd like on the X axis and swap out everything that says Red with whatever search term you'd like on the Y axis. You can also change the color from purple to something else; I just didn't want the default blue when one of my axes includes "Blue" to avoid any confusion.

Interactivity 1: Layering Charts

The first interactivity we're looking at is adding a bar that can be dragged across our graph to show the number of points within the area. This shows one way to add interactivity by creating 2 charts that are layered together with a slider to switch between them. As you'll see in the code, everything is tethered to the x-axis, but if the data that you were using would be better shown with a bar going up and down vertically, the code can be manipulated to be tethered to the y-axis instead.

The code for this has four parts to it, but when you are running the code, all four parts will go in the same Colab cell. 


	slider = alt.binding_range(min = 0, max = 90, step = 1)
	threshold = alt.param(name = "threshold", value = 0, bind = slider)

This part creates the slider that will change the visual from one graph type to another. For your data, change out the max value from 90 to whatever the maximum value on your x-axis is. If you make it too low, it won't slide across the entire graph, and if you make it too high the slider will be able to slide right off the graph. In the second line, changing the value from 0 will change where your slider will start at when the graph first loads. I have it set to 0 so that it starts on the y-axis, but you could set it to start somewhere in the middle if you wanted. 


alt.layer(
    alt.Chart(dataset).mark_circle(color="purple").encode(
   		x = alt.X("Blue:Q").title("Popularity of Searches for Blue"),
    	y = alt.Y("Red:Q").title("Popularity of Searches for Red"),
    	tooltip = ["Blue", "Red"]
	).transform_filter(
    	alt.datum["Blue"] >= threshold
	),

This block of code is practically identical to the block we used earlier to create our scatterplot. The important difference is the "transform_filter" at the end that will filter it based on where our threshold bar is on the x-axis. 


	alt.Chart(dataset).mark_circle(color="purple").encode(
    	x = alt.X("Blue:Q").bin(maxbins=10),
    	y = alt.Y("Red:Q").bin(maxbins=10),
    	size = alt.Size("count():Q").scale(domain = [0, 60])
    ).transform_filter(
		alt.datum["Blue"] < threshold
	),

This block of code makes our second chart, which in our case is showing the number of points in a 10x10 square. By changing the 'maxbins' number for both the x and y, you can change the size of those squares. In the line about size, the domain of the scale may need to be changed depending on how clustered your data is. And again, the "transform_filter" will filter it based on where the threshold bar is on the x-axis. 


	alt.Chart().mark_rule(color = "gray").encode(
   		strokeWidth = alt.StrokeWidth(value = 4),
    	x = alt.X(datum = alt.expr(threshold.name), type = "quantitative")
	)
).add_params(threshold)

This final part of the code will create our threshold line. You can change the color and thickness of the line if you like.

Interactivity 2: Stacking Charts

For this interactive visual, we'll create a heatmap of our data, and allow the user to change the bin size by using the slider. This isn't something that can be done with an easy change in the creation of the visual itself, so what we can do is stack each version on top of each other, then the slider chooses which one to put on the top.

Similar to Interactivity 1, there are two parts to this code, but both will be run in the same Colab cell. 


maxbins_options = [10, 30, 50, 70, 90]

slider = alt.binding_range(
    min=min(maxbins_options),
    max=max(maxbins_options),
    step=20,
    name="Max bins ",
)
maxbins = alt.param(name="maxbins", value=10, bind=slider)

This code block creates the options of the bins and the slider that will be used to switch between them. You could change how many bins you want at each step and how many steps you offer, just make sure that the step number in the slider equals the space between each of your bin options. 


layers = [
    alt.Chart(dataset)
    .mark_rect()
    .encode(
        alt.X("Red:Q")
        .bin(maxbins=n)
        .scale(zero=True)
        .axis(format="d", title="Popularity of Searches for Red"),
        alt.Y("Blue:Q")
        .bin(maxbins=n)
        .axis(format="d", title="Popularity of Searches for Blue"),
        alt.Color("count():Q").scale(scheme="purples"),
    )
    .transform_filter(f"maxbins === {n}")
    for n in maxbins_options
]

alt.layer(*layers).add_params(maxbins)

This big block of code creates a new layer on the stack for each of the bin options. The color scheme for the heatmap can be changed if you don't want it to be purple.

Interactivity 3: Date Ranges

We can do more with visuals than just use sliders. In this example, we'll look at how to interact with a visual by added a time component to it. We will add a start date and end date that can be selected by the user to look at a specific time range of the data.

Once again, there are three parts to this code, but all three will be run together in the same Colab cell. 


start_date = alt.param(
    name="start_date",
    value="2004-01-01",
    bind=alt.binding(input="date", name="Start date: "),
)
end_date = alt.param(
    name="end_date",
    value="2026-10-01",
    bind=alt.binding(input="date", name="End date: "),
)

This creates a parameter to specify the start date and end date for the data shown in the visual. The dates listed for the start date and end date values are the first and last dates in the dataset that I am using; yours might be different. 


chart = (
    alt.Chart(dataset)
    .mark_circle(color="purple")
    .encode(
    x = alt.X("Blue:Q").title("Popularity of Searches for Blue"),
    y = alt.Y("Red:Q").title("Popularity of Searches for Red"),
        tooltip=[
            alt.Tooltip("Time:T", title="Date"),
        ],
    )

This section of code creates the scatterplot, again looking very similar to the code from earlier. The biggest difference is that our tooltip now shows us the date that the point comes from. If your dataset uses something other than "Time" for the date column, you'll have to swap that out for the tooltip to work. 


	.transform_filter(alt.datum.Time >= alt.expr.timeParse(start_date, "%Y-%m-%d"))
    .transform_filter(alt.datum.Time <= alt.expr.timeParse(end_date, "%Y-%m-%d"))
    .add_params(start_date)
    .add_params(end_date)
)
chart

These transform filters and added parameters will do the start date and end date limitations that we're looking for. Like before, if your dataset has a header for the date that isn't "Time", you'll have to change that out in the "transform_filter" lines.

Interactivity 4: Window Selection

In this graph, we'll look at one final way to interact with visuals by creating a window that selects all the points within it, and can be tied to some other component. In our case, we will show the average of the Red search popularity within the window, but there are a lot of different ways that this could be used outside of that.

Like the previous three examples, this one is broken into four pieces, but all four pieces will be run together in the same Colab cell. 


brush = alt.selection_interval()

This line of code creates the ability to make the window to select certain data points. 


chart = alt.Chart(dataset).mark_circle().encode(
    x = alt.X("Blue:Q").title("Popularity of Searches for Blue"),
    y = alt.Y("Red:Q").title("Popularity of Searches for Red"),
    color = alt.when(brush).then(alt.value("purple")).otherwise(alt.value("grey")),
    tooltip = ["Blue", "Red"]
).add_params(brush)

Again, this builds off the initial scatterplot we made with no interactivity, but this time we're adding a color component that changes when the points are within the window. You can change the colors that the points will be if you want to. 


line = alt.Chart(dataset).mark_rule(color="orange").encode(
    y = "mean(Red):Q",
    size = alt.SizeValue(2)
).transform_filter(brush)

This section creates our average line. Again, with a different dataset or different goal in mind, the average line can be swapped out for some other piece that would be more insightful or useful. The size of the line and color can be changed. 


alt.layer(chart, line)

This line of code ties together the scatterplot with the average line.

Important Tips

If you're using a different dataset, make sure that all the "Red"s and "Blue"s are swapped out for your own data's x- and y-axis labels.

If you do get stuck, feel free to look at the Google Colab notebook to see if there is something that was missed.

When to Use This Tool

If you're more comfortable working with something that is familiar, or want to keep things consistent and already have Altair visuals, these could be a good way to add in some interactivity while using Altair to create the visuals.
